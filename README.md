# NYC Taxi ETA Prediction

## Week 3 Production-Grade Regression Benchmark

### Project Overview
This project predicts NYC Yellow Taxi trip duration before a trip begins using machine learning regression models.

### Objectives
- Predict taxi trip duration in minutes.
- Prevent data leakage.
- Build reproducible preprocessing pipelines.
- Compare multiple regression models.
- Perform hyperparameter optimization.
- Evaluate model performance.
- Explain model predictions using SHAP.

### Dataset
NYC TLC Yellow Taxi Trip Records (January 2023 – June 2023)
